# Organization meta repository

This directory documents the public `.github` org repository so agents can update profile and workflow assets without mistaking it for an application codebase.

## Map

These files describe the repo's public role and automation touchpoints.

- [[overview]] explains what this org-level repo owns and what it intentionally excludes.
- [[workflows]] explains how to treat org-facing workflow changes and shared automation assets.

## Update discipline

Keep these notes aligned with any change that affects the public org profile, shared issue forms, or org-level workflow behavior.

## Rules

Add or update the file that owns a concept, link with `[[wiki links]]`, keep the first paragraph after each heading short, and run `lat check` from the repo root when editing these files.
